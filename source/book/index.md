  近几年看过最好看的文娱文之一，无女主，涉及音乐写作画画等多样文娱产品，非常全面。
  不过作者有卖腐嫌疑，虽然是主角跟自己的主角卖腐。
  另外书中所有人有些时候有点降智，包括主角，就挺呆呆的，虽然很多人说主角塑造的很好，但个人感觉主角更偏向于一个系统的工具人，不过由于作者给主角打上了很多独特的标签，所以觉得主角塑造的好。
  总结：值得一看

都市：

- 捡漏-金元宝本尊（97/100）
  
  ```
  极少数三刷的书，强烈推荐。
  很喜欢书中的一句话——王侯有王侯的葬礼，枭雄有枭雄的孤坟，这句话完全是书中主角的写照。
  这本书的基石在于作者对于古玩字画瓷器等传统文博知识的大量铺陈，将捡漏这一行当写得神乎其神又步步有据。
  并且以宝物串联起了更加宏大的势力博弈，利用捡到的宝物在各个势力之间左右逢源。
  捡漏不只是简单地指捡漏国宝，更指的是利用尔虞我诈挑起争斗后在各个势力之间捡漏发展。
  极致的专注隐忍与鲜明的快意恩仇，赋予了小说极强的爽感。
  
  
  不过也有缺点，后宫展开单女主结束，主角的红颜多的有点冗余了，让我想起了某个神秘的二字作者，不过核心的几个女角色刻画还是很鲜明的。
  主角的性格也是一大问题，特别的冲！很多时候可以和平解决但是非要你死我活，行事风格有些紧绷与肃杀，缺少温情调剂，部分桥段戾气过重。
  其次就是中后期小剧情总是落入一种轮回——被轻视—反转打脸—夺宝结仇，这样的剧情有点多了，但是胜在高潮处够爽！
  主角也是亦正亦邪的，毕竟不是现代人，爱国但是不守法（主要有些人确实过分）。
  
  总结——瑕不掩瑜，绝对佳作！
  ```
